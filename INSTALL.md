# How to install and start dMAT Master Practice

No technical knowledge needed. There is **nothing to install**: the app is a single file that opens in your web browser, and it works **without internet** once downloaded.

**What you need:** a laptop or desktop computer (Windows or Mac) with **Google Chrome**, Microsoft Edge or Firefox. A computer is strongly recommended; phones are not supported well.

---

## Step 1 – Download the ZIP file

> This repository is private: you must be signed in to GitHub with an account the owner has invited, otherwise the link shows "404 – page not found".

1. Click this link: **[⬇ Download dMAT-Master-Practice.zip](https://github.com/krishna-ITTL/Dmat/raw/main/download/dMAT-Master-Practice.zip)**
2. Your browser downloads a file called **`dMAT-Master-Practice.zip`** (about 5 MB).
   - In Chrome, a small download icon appears at the top right; the file goes to your **Downloads** folder.
   - If the browser asks *"Keep or discard?"*, click **Keep**.

---

## Step 2 – Unzip (extract) the file

A ZIP file is a packed folder. You must unpack it first, or the app will not work properly.

**On Windows**

1. Open **File Explorer** (the yellow folder icon on the taskbar) and click **Downloads** on the left.
2. **Right-click** `dMAT-Master-Practice.zip` and choose **Extract All…**
3. Click **Extract**. A new folder named **`dMAT-Master-Practice`** opens.

**On Mac**

1. Open **Finder** and go to **Downloads**.
2. **Double-click** `dMAT-Master-Practice.zip`. A folder named **`dMAT-Master-Practice`** appears next to it.

> Tip: move this folder somewhere permanent, such as **Documents**, and keep it there. See "Keep your results" below.

---

## Step 3 – Open the app

1. Open the **`dMAT-Master-Practice`** folder.
2. **Double-click** **`dmat_master_practice.html`**.
3. The app opens in your web browser and you see this screen:

<p align="center"><img src="docs/images/home.png" alt="Home screen of the app" width="760"></p>

**If it opens in the wrong program** (for example Word or Notepad):
right-click `dmat_master_practice.html` → **Open with** → **Google Chrome** (or Microsoft Edge).

---

## Step 4 – Start practising

| I want to… | Click |
|---|---|
| Take a full timed exam simulation (about 3 hours) | **Set up the actual test** → **Full actual test** |
| Try just one part, e.g. Latin Squares | **Set up the actual test** → the part you want |
| Practise without a countdown | **Open practice** → **Start** |
| See my results and weak spots | **Practice analytics** or **Past attempts** on the home screen |

**During a question**
- Click an option to select it (it gets a blue outline). You can change it any time before submitting.
- Use **Next ▶ / ◀ Previous** or the numbered boxes at the bottom to move between questions.
- **Flag** marks a question you want to come back to.
- The big clock at the top right is your section time. The small **question time** shows how long you have spent on this question (the target is 75 seconds; it never stops you).
- Answers are shown only **after** you submit the section.

<p align="center"><img src="docs/images/figure-sequence.png" alt="A question screen with clock and options" width="760"></p>

**After a section** click **Review every question with answers** to see the correct answer (green), your wrong choice (red), your time and an explanation.

---

## Keep your results

Your results are saved **inside your browser on this computer**, not in the file. To keep them:

- Always open the app **from the same folder** with the **same browser**.
- Do **not** use a private / incognito window; nothing is saved there.
- Do **not** clear your browser's "cookies and site data"; that deletes your results.
- Results do not move to another computer.

---

## Problems?

| Problem | Fix |
|---|---|
| The page is blank or looks broken | You probably opened the file **inside** the ZIP. Do Step 2 (Extract All) first, then open the file from the extracted folder. |
| Windows asks "How do you want to open this file?" | Choose **Google Chrome** or **Microsoft Edge** and tick "Always use this app". |
| The browser warns the file "may be harmful" | Click **Keep**. It is a plain web page with no programs inside. |
| My previous results are gone | Check you are using the same browser and the same folder, not an incognito window. |
| The clock kept running while I was away | That is intended: like the real exam, the section time keeps running. If you close the page mid-section, the home screen offers **Resume section**. |
| Text or pictures are too small | Press **Ctrl** and **+** (Mac: **Cmd** and **+**) to zoom in, **Ctrl** and **0** to reset. |

---

## Updating to a newer version

Download the ZIP again (Step 1), extract it, and **replace** the old `dmat_master_practice.html` in your folder with the new one. Your results stay as long as the file is in the same folder and you use the same browser.
